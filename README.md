# 工资拔草机 💰✂️

> **买前过一审，工资自己守。**
> 想买东西先来「过审」，AI 专给不买的理由，帮你冷静。
> 备选名：冷静一下 / 拔草办公室 · 定位：理性消费趣味工具（记账/效率类目，完全合规）

「工资拔草机」把你的月薪折算成**时薪**，再把你每一笔「想买」折算成**生命小时数**（¥899 ≈ 你 37.5 小时的班），然后让 AI 抠门管家给这笔消费出一个「审批单」——该拔的草拔掉，该冷静的进冷静清单，该放行的放行但要聪明地买。

---

## 核心功能

| 功能 | 说明 |
|---|---|
| **工资设定** | 首次引导：月薪 + 每月工作天数/小时数 → 自动算出时薪常驻显示；之后每次判定都换算成「生命小时数」 |
| **拔草过审** | 输入想买的东西（名称+价格+可选：为什么想买/在哪看到的），**可附购物截图（多模态识图）**，AI 给三档判定之一：<br>🚫 **拔草**（别买，3~5 条理由）／😐 **冷静**（买前先回答的问题清单）／✅ **放行**（可以买，但必须给聪明买法：等大促/凑券/二手/同价位更优解） |
| **购物截图识别** | 商品页/直播间/购物车截图随单提交，识图模型（默认 `glm-4.5v`）先读出价格、优惠与商家话术（倒计时/仅剩N件/划线原价/已售10万+）再判定；截图与手填价格冲突以截图为准。截图自动压缩，台账只存缩略图，大图不落盘 |
| **置信拔草指数** | 0~100 量化判定置信度；每条理由带 1~5 ⚡扎心指数，逐条流式渲染 |
| **毒舌人格三选一** | 🧧温和记账师（温柔讲道理）／😈毒舌管家（阴阳怪气但幽默，绝不人身羞辱）／🛡️工资守护神（庄严悲壮「你又要辜负这个月的自己了吗」）。只换语气，不换判定逻辑 |
| **拔草台账** | 每次判定自动入库；首页大数字「本月已守住 ¥X」（只计 🚫 且标记「听劝没买」）、拔草成功率、累计守住总额 |
| **72 小时冷静期** | 😐 判定进冷静清单，72h 后回访「还想买吗」→ 回填结果（没买=拔草成功 / 买了=记入吃灰名单） |
| **吃灰名单（翻旧账）** | 标记「最后还是买了」的东西进吃灰名单；下次再买同类东西时，AI 提示词自动附上「你买过 XX，吃灰至今」的翻旧账上下文 |
| **分享卡 / 月度战报** | 一键生成「本月我为工资守住了 ¥X，拔草 N 件，最狠的一刀：XX（¥Y）」战报文本复制分享；单条判定可生成「AI 让我别买 XX 的理由」趣味卡 |

判定取材角度：时薪换算、买回吃灰概率、家里已有类似物、商家话术拆解（限时/限量/直播氛围）、替代方案、花呗白条分期的利息成本、二手残值。

**三档判定都会真实出现，不永远反对**——全反对会失去可信度。该买的刚需要放行。

## AI 输出与健壮性

- 判定要求严格 JSON（`verdict` / `confidence` / `reasons[]`(含 `sting`) / `questions?[]` / `alternatives?[]` / `saved_amount`），语气规范写进提示词：**毒舌≠羞辱，幽默不刻薄；禁止鼓励极端抠门；禁止任何借贷/理财产品推荐（工具不碰金融建议）**。
- 前端健壮解析：去 ```` ```json ```` 围栏、全角引号/尾逗号修复、verdict 同义词归一、数值越界钳制；**失败降级 Markdown 原文展示 + 手动归档**。
- 流式输出支持**增量解析**：理由写完一条就渲染一条（`parse_partial`，Python/JS 双端同构）。
- 多模态：附截图走 OpenAI `image_url` / Anthropic `image` 内容块协议；识图模型在设置页按服务配置。

## 架构（零第三方依赖）

- **后端/网页**：Python 标准库（`http.server` + `urllib`），零 pip 依赖。`python3 app.py` 起 `http://127.0.0.1:8772`
- **前端**：原生 JS，无构建步骤。`static/engine.js`（核心引擎）与 `engine.py` 严格同构，保证网页版与 APK 离线版判定/统计行为一致
- **双运行模式**：
  - `server` 模式（连本机 Python 服务，服务端流式转发 + 数据存 `data/`）
  - `client` 模式（APK / 直接双开 index.html）：数据在 localStorage，AI 请求**离线直连**厂商端点。安卓内置自研 `StreamHttpPlugin`（OkHttp SSE 原生流，绕过 WebView CORS）；`detectMode` 强制原生环境走 client，200-HTML 兜底不误判
- **安卓**：Capacitor 7 壳 + `mobile/build.sh` 一键出签名 APK；挖孔屏适配（`adjustMarginsForEdgeToEdge: force`）

## 快速开始（网页版）

```bash
python3 app.py                # http://127.0.0.1:8772
python3 app.py --host 0.0.0.0 # 局域网内手机也可访问
```

首次打开会引导你设定工资（只存本机），然后在「设置」里配置 AI 服务（默认 GLM 智谱，填 API Key）即可开始过审。

## 安卓 APK

 Releases 页下载 `工资拔草机.apk` 直接安装。

本地构建（需 JDK 21 + Android SDK 放在 `tools/`，见 `mobile/build.sh` 头部说明）：

```bash
cd mobile && ./build.sh
# 产出 工资拔草机.apk（正式签名版）与 工资拔草机-debug.apk
```

## 测试

```bash

node tests/test_engine.js                                 # JS 引擎（与 Python 用例同构）
node tests/test_app_client.js                             # 模拟 Capacitor 原生环境 client 模式回归
```

覆盖：判定 JSON 解析健壮性（围栏/杂质/全角/尾逗号/越界钳制）、时薪换算、台账统计聚合（**守住金额只计 🚫 且听劝**）、冷静期 72h 回访逻辑（注入时间偏移）、翻旧账上下文注入、API 集成（stub LLM 流式全链路）、模拟 Capacitor 原生环境（强制离线 + 200-HTML 兜底不误判 + 伪造 StreamHttp 插件跑真流式）。

## 数据与隐私

工资、台账等全部数据只保存在本机（网页版在 `data/`，App 在浏览器本地存储），不上传、不联网同步；API Key 只存本机，AI 请求直连厂商端点，不经任何第三方。
